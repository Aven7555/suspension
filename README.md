# SuspensionX Malaysia Web App Demo

This is a static no-server web app prototype for a dealer-price luxury suspension repair platform.

## What is included

- Customer front-end landing page
- Price comparison estimator
- Customer enquiry form
- Owner back-end dashboard
- Lead/job pipeline
- Workshop status update editor
- Dealer cost vs retail price profit tracking
- Repair float/deposit tracking
- Warranty/insurance add-on section
- Customer status link demo
- CSV export
- Print report function

## How to use

1. Open `index.html` in any browser.
2. Use the customer page to submit enquiry.
3. Go to Owner Back-End to edit status, dealer cost, retail price and warranty.
4. Use Print Report or Export CSV for monthly reporting.

## Deployment

Upload all files to a GitHub repository and enable GitHub Pages from the root folder.

## Important

This is a prototype. It uses browser localStorage only, so data is stored only on the device/browser. For real business use, connect it to Supabase/Firebase/Airtable and add real login, file uploads, payment and access control.
